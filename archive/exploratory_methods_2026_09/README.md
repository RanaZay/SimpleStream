# Archived Exploratory Methods

This directory contains experiment launchers and older method variants that were useful during development but are not part of the selected PRISM paper method.

These files are archived rather than deleted so that ablations and negative results remain traceable.

The selected paper path remains in the main repository:

- corrected exact Recent-6 baselines
- PRISM evidence-contract implementation
- final StreamingBench, OVO-Bench, EgoSchema500, and StreamBench-v0.3 launchers
- analysis scripts needed to reproduce paper tables

Do not use archived launchers for main paper results unless explicitly reproducing an ablation.
